# mamolii グラフ電卓 — 機能仕様（案件 T-20261019-DESMOS）

制定: 2026-10-19。根拠: 利用者依頼（Desmosクローン・日本の高校数学レベル・日本人学生向け）＋ Desmos機能調査(docs/RESEARCH.md)。
利用者指定の独自要件: ①変数は x, y と a, b（a/bはスライダー変数） ②a/bに別名表示(エイリアス)を設定できる ③日本語UI・日本語チュートリアル ④GitHub経由でCloudflareへ配信。

## スコープ（実装するもの）

### 式の種類
| 種類 | 入力例 | 動作 |
| --- | --- | --- |
| 明示関数 y=f(x) | `y=x^2`, `y=2x+1` | 1px刻みでプロット。漸近線(tan等)で線を切断 |
| 逆関数形 x=g(y) | `x=3`, `x=y^2/4-2` | 縦方向にサンプリングしてプロット |
| 陰関数 F(x,y)=0 | `x^2+y^2=25`, `y^2=4x`, `x^2/4+y^2/9=1`, `x^2-y^2=1` | マーチングスクエア法(7pxグリッド+線形補間)で描画 |
| 不等式領域 | `y>x^2`, `x^2+y^2<=9`, `≦≧`も可 | 4pxブロックで領域塗り(半透明)。厳密(`,<,>`)は境界破線・非厳密は実線 |
| 点 | `(1,2)`, `(a, a^2)` | プロット。定数点はドラッグで移動可(座標は目盛りにスナップ) |
| スライダー定義 | `a=2.5` | スライダーaの値を2.5に設定 |
| 単独の式 | `x^2`, `sin(x)` | y=x^2 として解釈 |
| 導関数 | `y=d/dx(x^3)` | 数値微分(中心差分)でプロット |

### スライダー（a, b）
- 式に `a` または `b` を含めると、スライダー行が自動追加（既定: 値1, 範囲 -10〜10, 刻み 0.1）
- ▶ボタンでアニメーション（往復）。⚙で最小値・最大値・刻み・別名表示を設定
- 複数の式で同じ変数を共有すると全グラフが連動
- 行を削除し他の式からも参照されなくなったらスライダー行も自動削除

### 別名表示（独自機能・利用者指定）
- 各スライダー変数 a, b に別名（最大6文字: 例 `x`, `p`, `n`, `k`）を設定できる
- 設定すると式リストの数式プレビューとスライダー行の表示で、a/b が別名で点線下線＋色付き表示される（内部計算は a, b のまま → グラフは変わらない）
- 用途: 数Bの数列で `a` を `n` と表示する、教材でパラメータを `p`, `q` と見せる等
- ホバーで「内部変数 a の別名表示」と表示され、混同を防ぐ

### 関数・定数（パーサ対応一覧）
- 三角: `sin cos tan`、逆三角: `arcsin arccos arctan`（`asin acos atan`も可）
- 対数指数: `log`（常用）, `ln`（自然）, `sqrt`/`√`, `^`
- その他: `abs`/`|x|`, `floor`, `ceil`, `round`, `max(a,b)`, `min(a,b)`, `mod(a,b)`, `sign`
- 定数: `pi`/`π`, `e`
- 記法: 暗黙の乗算（`2x`, `3sin(x)`, `(x+1)(x-2)`, `ax`）、全角記号（`×÷−²³`）、`≦≧`
- 角度: ラジアン既定、左下ボタンで度数法に切替（三角関数と逆三角関数に適用）

### 画面操作
- ドラッグでパン、ホイールでズーム（カーソル位置基準）、＋/−/⌂ボタン
- 曲線にマウスを乗せると座標ラベル表示（トレース）、点は近接で座標表示
- 目盛りは 1・2・5×10^n の見やすい刻みを自動選択
- 入力はブラウザ(localStorage)に自動保存。`?add=<式>`（`~`区切りで複数）で外部から式を渡せる

### UI
- 日本語UI（式リスト、エラーメッセージ、設定、すべて日本語）
- 式ごとに: 6色パレット（Desmos準拠 #c74440 #2d70b3 #388c46 #6042a6 #fa7e19 #000000）、線スタイル（実線/太/細/破線/点線）、表示/非表示、削除
- 数式プレビュー: 分数は縦組み、べき乗は上付き、√は上線で美しく表示
- エラーは日本語で行内表示（例: 「使えない文字「z」です。変数は x, y, a, b だけが使えます。」）
- モバイル対応（720px以下で式リストがオーバーレイ切替）

## スコープ外（本版では未対応と明記）

調査結果のP1/P2のうち、品質を保つため本版では実装しない。UI/チュートリアルで「未対応」と正直に案内する。
- 媒介変数表示 `(cos t, sin t)`、極座標 `r=f(θ)`、極限
- 積分 `∫`、総和 `Σ`、場合分け `{}`、定義域制限 `{0<x<2}`
- 関数定義 `f(x)=...`、リスト `[1,2,3]`、テーブル、回帰 `~`、統計分布
- 3D、複素数、行列、Geometry作図、アカウント・共有リンク（代わりに localStorage保存とURL `?add=` を提供）

## 技術構成

- 依存ゼロの素のHTML/CSS/JavaScript(ES Modules)。ビルド不要 → どの配信先にも移設可能（WEB_DELIVERY.md 第3条）
- `app/js/parser.js` 字句解析＋再帰下降パーサ＋整形出力
- `app/js/evaluator.js` AST→JSクロージャコンパイル（角度モード切替対応）
- `app/js/classify.js` 式種別判定（UI非依存の純関数）
- `app/js/grapher.js` Canvas描画（明示/陰/不等式/点/グリッド）
- `app/js/pretty.js` 数式プレビューDOM生成（別名表示対応）
- `app/js/app.js` UI制御・状態・保存
- `app/tutorial/` 日本語チュートリアル（自己完結HTML）
