1. はじめに

アプリで何ができるか、入力の保存のしくみを知る。

mamolii グラフ電卓でできること

  • グラフがすぐ描ける：左側の式リストに数式を入れると、その場でグラフが描かれます。インストールも登録も不要のWebアプリです。
  • いろいろな式：y = f(x)、x = g(y)、円などの陰関数、不等式の領域、点、導関数 d/dx に対応。
  • スライダー：式に a や b を書くと、値を動かせるスライダーが自動で追加されます。
  • 別名表示（独自機能）：スライダー変数 a の見える名前を「n」や「p」などに変えられます（第4章で詳しく）。

入力の保存について（安心して使うために）

  1. 式リストに入力した式は、自動でブラウザに保存されます。保存ボタンを押す必要はありません。
  2. ただし保存先は「このブラウザの中」です。別の端末や別のブラウザには引き継がれません。また、ブラウザのサイトデータを削除すると消えることがあります。
  3. 大事な式は、メモやスクリーンショットにも残しておくと安心です。
あらかじめご了承ください（未対応の機能）
次の機能には対応していません。対応していると誤解しないよう、このページでは正直に書いています。
媒介変数表示、極座標（r = …）、積分（∫）、場合分け（{ }）、定義域制限（{ }）、表（テーブル）、関数定義（f(x) = …）、3Dグラフ。
まずは一度さわってみましょう。クリックするとアプリが開いて式が入力された状態になります。

変数は x, y とスライダー変数 a, b のみです。k, n, m, z など他の文字は入力エラーになります。詳細は第11章の「よくある質問」で説明します。

2. 最初のグラフを描いてみよう

y = x2 を入力して、画面の操作（ズーム・移動・初期表示）ができるようになる。

  1. アプリを開いて、左側の式リストの1行目に y=x^2 と入力します（すべて半角英数）。
  2. 入力した瞬間に、右側に放物線 y = x² が描かれます。「実行」ボタンなどは不要です。
  3. 移動：グラフの場所をドラッグすると、画面をぐりぐり動かせます。
  4. ズーム：マウスホイールで拡大・縮小できます。画面の＋−ボタンでも調整できます。
  5. 初期表示に戻す：画面の ⌂ ボタンを押すと、最初の表示に戻ります。
  6. 座標を読む：曲線にマウスを乗せると、その位置の座標が表示されます。
放物線 y = x² を描いて操作を練習しよう。

入力は基本半角です。掛け算の * の代わりに ×、割り算の / の代わりに ÷ を入力してもOKです。

3. スライダーで動かす

y = a x2 の a をスライダーで動かし、放物線の開き方の変化をつかむ。

  1. 式リストに y=a x^2 と入力します。
  2. 式の中の a を見つけると、アプリが自動で a のスライダー行を追加します（初期範囲は −10〜10、刻みは 0.1）。
  3. スライダーのつまみを動かすと、グラフがリアルタイムに変化します。a が大きいほど細く、小さいほど開いた放物線になります。
  4. ▶（アニメーション）ボタンを押すと、a が自動で動き続けます。変化のようすを眺められます。
  5. ⚙（設定）ボタンでは、スライダーの最小値・最大値・刻みを変更できます。
  6. 「a を 2 に固定した状態で試したい」場合は、式リストに a=2 のように書けば、a の値を決められます。
a のスライダー付きで開く。 a を 2 に固定して開く。

b も同じようにスライダー変数として使えます。2つの係数を同時に動かしたいとき（例：y=a x+b）に便利です。

4. 別名表示（このアプリ独自機能）

スライダー変数 a の見た目上の名前を「p」「n」などに変える方法を覚える。ただし見た目だけが変わり、計算の内部では a のままということを理解する。

問題の紙には p や n などの文字で書かれているのに、アプリでは変数は x, y, a, b しか使えません。「式を問題どおりの文字で読みたい」ときに役立つのが、このアプリ独自の別名表示です。

  1. 式リストに y=a x^2 と入力して、a のスライダー行を出します。
  2. スライダー行の ⚙（設定）を開き、「別名表示」の欄に p と入力します。
  3. 式リストとスライダーの表示で、a が p という名前で色付きで見えるようになります。たとえば y = p·x² のように見えます。
  4. このとき計算の内部では a のままです。スライダーを動かせば p の値が変わります。別名は「表示の名前」だけのものです。
  5. 元に戻すには、⚙で別名表示を空にします。

数B（数列）で使う例：別名を「r」にしてみる

  1. 初項 1・公比 r の等比数列の増え方を調べたいとします。式リストに y=a^x と入力します。このとき x は「項数 n」のつもりで読み、a を「公比 r」の役割にします。
  2. ⚙で a の別名表示を r にすると、式リストは y = rx と見えます。「公比 r を 1 より大きくすると項はどんどん大きくなり、0 から 1 だと収束する」ことがグラフで見て取れます。
  3. 公比は正なので、⚙でスライダーの最小値を 0.1 くらいにしておくと見やすいです。

別名は x, y, k, n など好きな名前を設定できます。数列の問題のように n の文字を式の中で見たいときも、同じ手順で a の別名表示を「n」にすれば、式リストには n と色付きで表示されます（入力と計算は a のままです）。

試すボタンで式を入れたら、⚙から別名表示を設定してみよう。

別名表示はあくまで「見た目」です。入力するときは a と打つ、という点だけ忘れないでください。

5. いろいろな関数

三角関数・指数対数・絶対値のグラフを入力し、角度の単位（ラジアン／度数法）を切り替えられるようになる。

三角関数（数学I・数II）

  1. 式リストに y=sin(x) と入力すると、正弦曲線が描かれます。
  2. 角度は初期状態でラジアンです。sin(π/2) = 1 のようにラジアンで計算されます。
  3. 度数法（°）で使いたいときは、画面左下のボタンで度数法に切り替えます。切り替えると sin(30) = 0.5 のようになります。
  4. 使える関数：sin, cos, tan、逆三角関数は arcsin, arccos, arctan（または asin, acos, atan）。

指数関数と対数関数（数II）

  1. y=2^x と入力すると指数関数、y=log(x) と入力すると対数関数が描かれます。
  2. log は常用対数（底 10）、ln は自然対数（底 e）です。
  3. y=x も一緒に入れると、y = 2x と y = log(x) が直線 y = x について対称（逆関数の関係）になっているのが確かめられます。
  4. 対数のグラフは、定義より x > 0 の範囲にしか描かれません。

絶対値（数学I）

  1. y=abs(x-1) と入力します。y = |x − 1| のグラフが描かれます。
  2. 縦線2本を使った |x-1| の形でも入力できます。
  3. 他にも sqrt（または √）、floor, ceil, round, max(a,b), min(a,b), mod(a,b), sign(x) が使えます。
三角関数：左下のボタンで度数法への切替も試そう。 指数・対数と y=x： 絶対値：

定数は pi または π、自然対数の底は e が使えます。例：sin(pi/6)、e^x。

6. 図形のグラフ

直線・円・楕円・放物線・双曲線を入力して描けるようになる。点を置いて動かしてみる。

y と x が混ざった式（陰関数）も、そのまま入力するだけで描けます。

図形入力例グラフ
直線y=2x+1
円（中心原点・半径5）x^2+y^2=25
楕円x^2/4+y^2/9=1
放物線（y が主役）y^2=4x
双曲線x^2-y^2=1

点を置いて動かしてみる

  1. 式リストに (3,4) のように入力すると、その座標に点が置かれます。
  2. 点はマウスでドラッグして動かせます。動かすと座標の値も変わります。
  3. 円 x^2+y^2=25 と一緒に点 (3,4) を置くと、点が円周の上にあることを確かめられます。点をドラッグして円の外へ動かしてみましょう。
5つの図形をまとめて入力。 円と点。点はドラッグで動かせます。

y^2=4x のように「y が主役」の放物線も y= の形に直す必要はありません。陰関数としてそのまま入力するのがコツです。

7. 不等式と領域

不等式を入力して領域を塗りつぶし、「破線の境界」と「実線の境界」の違いを見分けられるようになる。

  1. 式リストに y>x^2 と入力すると、放物線 y = x² の上側の領域が塗りつぶされます。
  2. このとき放物線の境界線は破線で描かれます。これは「境界を含まない（≠）」という意味の合図です。
  3. 次に x^2+y^2<=9 と入力すると、半径 3 の円の内部の領域が塗りつぶされます。こちらの境界円は実線です（境界を含む）。
  4. 不等号は < > <= >= のほか、全角の ≦ ≧ でも入力できます。
  5. 式を書き換えて「<」と「<=」を切り替えると、境界線の見た目が変わることを確かめてみましょう。
放物線の上側（境界は破線）。 円の内部（境界は実線）。 同じ円で「<」と「<=」を見比べる。

ルールはシンプルです。厳密な不等号（< >）は境界が破線、≤（<= ≦）≥（>= ≧）は境界が実線。試験の答案と同じ感覚で読めます。

8. 微分を見る（数II・数III）

d/dx の入力方法を覚え、導関数のグラフと接線の傾きの関係をつかむ。

導関数のグラフを描く

  1. 式リストに y=d/dx(x^3) と入力します。これは x³ を微分した導関数 3x² のグラフです。
  2. 比べるために y=3 x^2 も入れてみましょう。2本のグラフがぴったり重なります。
  3. d/dx は半角で入力し、微分したい式をあとのかっこ ( ) で囲むのが決まりです。

接線の調べ方（スライダーとの合わせ技）

  1. y=a x^3-3x と y=d/dx(a x^3-3x) の2式を入力します。2つ目の式は 1つ目の式を微分したものなので、もとの曲線の「傾き」だけを取り出したグラフになります。
  2. 導関数の値が正のところでは曲線は右上がり、負のところでは右下がりです。
  3. 導関数の値が 0 になる x（グラフが x 軸と交わる点）の近くで、もとの曲線の山や谷（極値）が来ます。
  4. スライダーで a を動かすと、山や谷の位置がどう動くかを観察できます。
x³ の導関数と 3x² が重なることを確認。 スライダー a と組み合わせて極値を探る。

曲線にマウスを乗せると座標が読めるので、導関数の値が 0 になる x を探すときにも役立ちます。

単元入力する式ねらい

11. よくある質問

エラーメッセージの読み方と、つまずきやすい点を解消する。

「使えない文字」というエラーが出ました

変数は x, y とスライダー変数 a, b の4つだけです。k, n, m, z などの文字は入力エラーになります。これは他のグラフ電卓（Desmosなど）と違う点なので注意してください。

数列の一般項などで n を使いたいときは、a の別名表示を「n」にする（第4章）ことで、式リスト上は n と色付きで表示されます。入力と計算は a のままです。

式を入れたのにグラフが表示されません
  • log(x) は x > 0、sqrt(…) の中身が負の場所は、数学的に値が存在しないため描かれません。ズームアウト（ホイールや−ボタン）して範囲を広げてみてください。
  • x^2 のように x だけを含む式は y = x² として自動で描かれます。真っ白な場合は ⌂ ボタンで初期表示に戻してみてください。
  • 全角文字が混ざっていないか確認してください（² ³ × ÷ ≦ ≧ π など一部の記号は対応しています）。
Desmos のように f(x)=x^2 と書きましたが動きません

このアプリは関数定義（f(x) = …）には対応していません。同じグラフにしたい場合は x^2 または y=x^2 と入力してください。

同様に、表（テーブル）・場合分け { }・定義域制限 { }・積分 ∫・媒介変数表示・極座標（r = …）・3D にも対応していません。誤って対応しているものと考えないよう、ご注意ください。

角度が思ったのと違います（sin 30 が 0.5 にならない）

角度は初期状態でラジアンです。sin(π/6) = 0.5 のように計算されます。度数法（30°=0.5）で使いたいときは、画面左下のボタンで度数法に切り替えてください。

入力した式は保存されますか？

自動でブラウザに保存されます。ただし保存は「このブラウザの中」だけなので、別の端末や別のブラウザには引き継がれません。ブラウザのサイトデータを削除すると消えることがあるので、大事な式はメモにも残しておきましょう。

点を自由な位置に動かせますか？

はい。(1,2) のように入力した点は、マウスでドラッグして動かせます。動かした位置の座標に点が移動します。

スライダーの動く範囲を変えられますか？

スライダー行の ⚙（設定）で、最小値・最大値・刻みを変更できます。初期値は −10〜10・刻み 0.1 です。⚙では別名表示も設定できます（第4章）。

エラーの見た目を知っておくのも勉強です。わざと使えない文字 k を入れてみましょう（アプリに式 y=k x が渡されます）。

エラーが出たら慌てずに、式の中の文字を確認。変数は x, y, a, b の4つだけ、これさえ覚えれば入力ミスの大半は防げます。
